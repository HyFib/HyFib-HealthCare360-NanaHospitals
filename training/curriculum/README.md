# Curriculum: who watches what

Written by `training/pipeline/curriculum.mjs` from the code (each role's menu: `role-menus.json`) and the
storyboards. Do not edit by hand: change a storyboard, then run the script again.

35 videos: 3 shared, 32 for a role. Every member of staff watches the shared
videos first, then their role's, just before their department's go-live wave
([MODULE-ROLLOUT-PLAN.md](../../docs/deployment/MODULE-ROLLOUT-PLAN.md), section 5).
